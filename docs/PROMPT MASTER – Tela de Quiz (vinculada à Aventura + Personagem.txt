Quero que você crie a funcionalidade COMPLETA da **Tela de Quiz** do meu jogo educacional chamado **Lutaver**, seguindo este fluxo:

1. O jogador entra no painel: `/player/dashboard`
2. Clica no menu **Jogar** → `/play`
3. Na página `/play`, ele vê uma lista de aventuras (cards)
4. Em cada aventura existe um botão **"Jogar Agora"**
5. Ao clicar em "Jogar Agora", o jogador é levado para a **Tela de Quiz** daquela aventura

====================================================================
🧱 1. STACK E ARQUITETURA
====================================================================

Use:
- Node.js + Express
- EJS como view engine
- Sequelize + MySQL
- Sessão com express-session
- Arquitetura MVC

Entidades principais já existentes:
- `User`       → usuário logado
- `Character`  → personagem do usuário
- `Adventure`  → aventura escolhida
- `Question`   → questões ligadas à aventura/disciplinas

Regras:
- Código em INGLÊS
- Interface (telas, labels, botões) em PORTUGUÊS do Brasil

====================================================================
🧩 2. RELAÇÕES IMPORTANTES
====================================================================

Considere as relações:

- `User` hasMany `Character`
- `Character` belongsTo `User`

- `Adventure` belongsTo `Discipline`
- `Adventure` hasMany `Question`
- `Question` belongsTo `Adventure`

Na **Tela de Quiz**, preciso:
- Saber qual **Adventure** está sendo jogada
- Saber qual **Character** está jogando
- Carregar as **Questions** dessa aventura

Sugestão de rota de quiz:
- `/play/quiz/:adventureId/:characterId`

Você pode ajustar, mas explique como o fluxo fica amarrado.

====================================================================
🎮 4. FUNCIONAMENTO DA TELA DE QUIZ
====================================================================

Na Tela de Quiz, quero:

1. Mostrar informações da aventura no topo:
   - Nome da Aventura
   - Disciplina
   - Ano Escolar
   - Dificuldade
   - XP de Recompensa

2. Mostrar informações do personagem:
   - Nome do personagem
   - Nível ou XP atual (se existir)
   - Talvez um ícone/avatar simples

3. Lógica de perguntas:
   - Carregar uma lista de questões da aventura (via Sequelize)
   - Armazenar no backend (sessão ou estrutura de controle) qual é a questão atual
   - Exibir **uma pergunta por vez** com alternativas A, B, C, D
   - Jogador seleciona uma alternativa e clica em **Responder**

4. Ao responder:
   - Verificar se a resposta está correta
   - Exibir feedback:
     - "Você acertou!" (verde)
     - "Você errou!" (vermelho)
   - Exibir a EXPLICAÇÃO da questão (campo explanation)
   - Atualizar um controle de progresso (acertos/erros)
   - Botão **"Próxima questão"**

5. Ao terminar todas as questões:
   - Exibir uma **Tela de Resultado do Quiz**:
     - Quantidade de questões respondidas
     - Quantas acertou
     - Percentual de acerto
     - XP ganho
     - Afinidade na disciplina (se houver, ex.: +1 afinidade em Matemática)
   - Botão "Voltar para Minhas Aventuras"
   - Botão "Jogar novamente" (opcional)

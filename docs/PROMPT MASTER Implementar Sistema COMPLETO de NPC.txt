📌 FICHA DO NPC – BLOCOS 01 AO 05 (CAMPOS DO MODEL)
====================================================================

Use os BLOCOS abaixo para definir os CAMPOS do model/migration de NPC.

--------------------------------------------------
🟦 BLOCO 01 — IDENTIDADE BÁSICA
--------------------------------------------------
Campos obrigatórios no model:
- name (STRING) → Nome do NPC
- type (STRING) → valores esperados: 'teacher', 'student', 'staff', 'boss', 'npc'
- subject (STRING, allowNull true) → Disciplina associada (para professores)
- grade_level (STRING, allowNull true) → Ano/série de atuação
- location (STRING) → Local onde aparece (corredor, biblioteca, sala X, cantina)
- avatar (STRING, allowNull true) → caminho da imagem / ícone
- personality (STRING, allowNull true) → calmo, bravo, alegre, misterioso…
- short_description (STRING) → descrição curta (1 linha)
- long_description (TEXT) → história, personalidade, papel

--------------------------------------------------
🟩 BLOCO 02 — FUNÇÃO NO JOGO
--------------------------------------------------
Campos no model:
- role_flags (STRING ou JSON em TEXT) → guarda o papel do NPC no jogo (ex.: 'quest_giver,shop,quiz,boss')
- starts_adventure_ids (TEXT) → lista de IDs de aventuras que ele pode iniciar (pode ser JSON em TEXT)
- shop_id (INTEGER, allowNull true) → caso seja vendedor, pode referenciar uma futura tabela de lojas
- main_discipline (STRING, allowNull true) → ainda reforça a disciplina, para quizzes
- map_zone (STRING) → qual mapa/setor pertence (ex.: 'corredor_1_andar', 'biblioteca')

--------------------------------------------------
🟧 BLOCO 03 — CARACTERÍSTICAS DE JOGO
--------------------------------------------------
Campos no model:
- difficulty (STRING) → 'easy', 'medium', 'hard', 'boss'
- participates_in_battle (BOOLEAN) → se entra em combates/testes
- stat_strength (INTEGER, default 0)
- stat_dexterity (INTEGER, default 0)
- stat_constitution (INTEGER, default 0)
- stat_intelligence (INTEGER, default 0)
- stat_reasoning (INTEGER, default 0)
- stat_luck (INTEGER, default 0)
- math_affinity (INTEGER, default 0) → exemplo de afinidade especial
  (pode ser genérico: 'main_affinity' se quiser simplificar)

--------------------------------------------------
🟨 BLOCO 04 — COMPORTAMENTO E DIÁLOGOS
--------------------------------------------------
Campos no model:
- dialogue_greeting (TEXT) → fala de apresentação
- dialogue_farewell (TEXT) → fala de despedida
- dialogue_start_quest (TEXT) → fala ao iniciar aventura/missão
- dialogue_success (TEXT) → fala de sucesso (quando o jogador passa)
- dialogue_failure (TEXT) → fala de falha (quando não atinge 70%)

--------------------------------------------------
🟥 BLOCO 05 — INTEGRAÇÕES FUTURAS
--------------------------------------------------
Campos no model:
- linked_shop_key (STRING, allowNull true) → chave de loja vinculada
- linked_adventure_keys (TEXT, allowNull true) → lista (JSON) de aventuras vinculadas
- linked_quiz_discipline (STRING, allowNull true) → disciplina/tema associado
- special_reward_info (TEXT, allowNull true) → descrição de recompensas especiais, acesso, etc.

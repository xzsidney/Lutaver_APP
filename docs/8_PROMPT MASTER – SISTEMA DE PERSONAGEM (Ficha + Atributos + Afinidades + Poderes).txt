👤 3. MODEL Character (personagem)
======================================================================
Crie tabela **characters** com os campos:

Identidade:
- id
- name (string)
- school_year (int) — série atual
- current_map (string ou FK opcional para tabela maps)

Atributos (6 básicos):
- strength (int)
- dexterity (int)
- constitution (int)
- intelligence (int)
- reasoning (int)
- luck (int)

Pontos:
- evolution_points (int) — pontos disponíveis para distribuir

Afinidades:
- affinities_json (JSON) ou criar tabela separada (preferível):
  Ex: matemática: 3, português: 1, ciências: 2...

Progresso:
- total_xp (int)
- level (int)

Opção avançada:
- inventory_json (opcional)
- title (apelido/honraria do personagem)

======================================================================
📚 4. MODEL CharacterAffinity (afinidades por disciplinas)
======================================================================
Preferencial usar tabela separada:

Tabela: character_affinities

Regra:

======================================================================
📈 8. SISTEMA DE EVOLUÇÃO
======================================================================

Atributos:
- evolution_points podem ser gastos para aumentar qualquer atributo.
- Cada aumento custa 1 ponto.
- Valor máximo inicial: 10 (ajustável)

Afinidades:
- Aumentam automaticamente após quizzes.
- Cada quiz concluído aumenta +1 afinidade na disciplina da aventura.
- Pode ter afinidade máxima configurável (ex: 10).

Níveis:
- XP sobe ao completar aventuras/quiz.
- level = floor(total_xp / 100)

======================================================================
🔐 9. REGRAS PARA APRENDER PODERES
======================================================================

Um poder só pode ser aprendido se:

affinity_level(disciplina) >= required_affinity

Tela deve mostrar:
- Poderes disponíveis
- Poderes bloqueados (com explicação)
- Botão “Aprender” se disponível
